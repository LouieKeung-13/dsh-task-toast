# dsh-task-toast

> 面向 [DeepSeek Harness](https://www.deepseek.com/harness/)（DSH）的任务完成通知插件。

[English documentation](README.md)

任务完成时通过系统通知或 DSH 内浮层提醒。通知可显示简短结果摘要，点击后打开来源会话；Windows 桌面版还会先恢复最小化或隐藏在托盘中的主窗口。

## 功能

- **跨平台系统通知**：在支持的 Windows 和 macOS 客户端使用系统通知；投递不可用时回退为 DSH 内提示。任务完成通知在自定义音效成功时使用该音效；失败时允许系统默认声音。错误通知保留系统默认声音。
- **结果摘要与会话回跳**：摘要最多 240 个字符。Windows 桌面端点击通知会先恢复主窗口，再打开来源会话。
- **应用内提示和历史**：查看结果、稍后提醒、忽略，并可回看本地通知历史。
- **可选提示音**：轻柔、清晰两种本地合成音效。选择音效时会试听；后台 Web Audio 被挂起时会尝试恢复，失败时系统通知改用操作系统提示音，避免完全静音。
- **前台感知**：正在查看且仍在运行的会话不弹出打断性提示。
- **中英文设置**：主题、位置、自动消失及不同任务来源。
- **dshmarket 托管更新**：插件不再自行覆盖安装文件或执行包管理命令。

## 安装

### DSH 桌面应用

打开 **插件 → 添加插件 → 安装第三方插件**，输入：

```text
https://github.com/LouieKeung-13/dsh-task-toast
```

安装并启用即可。安装包已包含 Host 和 Client 构建产物，不需要在本机编译。

### DSH Web profile

```sh
dsh plugin --profile web add github:LouieKeung-13/dsh-task-toast
```

按需将 `web` 替换为目标 profile。桌面 profile 由 DSH 桌面应用管理。

## 更新

插件市场渠道只考虑 **dshmarket**。市场收录需单独通过目录审核；收录后可在 **插件 → 插件市场 → 已安装** 管理更新。市场自动检查只提醒，不会静默安装。直接从 GitHub 安装的副本不会自动转成市场安装来源。

Host 报告更新成功后，插件通过 DSH 已有的 Host/Client 重载机制生效。若 Host 要求刷新页面或重启，请按提示操作。首次从未清理路由的旧版迁移时，仍需完整重启一次，以清除旧进程留下的路由。

## 快速开始

1. 打开 **设置 → 任务提示** 并启用插件。
2. 将 **任务完成** 设为 **系统通知**，并允许系统通知权限。
3. 保持 **显示结果摘要** 开启可查看简短预览；若任务内容敏感请关闭，操作系统可能在锁屏通知中显示正文。
4. 在 **任务完成音效** 中选择「轻柔」或「清晰」。选择即试听，也可按 **试听** 重播。
5. 用真实后台任务验证摘要和会话回跳。测试通知不包含真实任务结果。

所选提示音保存在当前浏览器存储中；其他通知设置和队列由运行中的 Host 进程持有。完整退出 DSH 后，请重新检查并设置这些选项。

## 通知行为

| 设置 | 行为 |
| --- | --- |
| **系统通知** | 发送一条操作系统通知。权限被拒、接口不可用或投递失败时回退为一条应用内提示。如果所选 Web Audio 音效无法恢复，系统通知允许使用操作系统自己的提示音。 |
| **应用内提示** | 在 DSH 内显示结果，并提供查看、稍后、忽略操作。 |
| **关闭** | 关闭对应通知类别。 |
| **显示结果摘要** | 从最新已回答的用户回合提取助手普通文本；不显示 reasoning、工具调用/结果或旧回合内容。 |
| **任务完成音效** | 关闭、轻柔或清晰。音效在本地合成；选中即试听，任务到达时再次尝试播放。后台音频策略可能限制 Web Audio。 |

系统通知只含最多 240 个字符的纯文本预览，不是完整对话；插件不渲染 HTML，也不执行结果内容。通知显示、声音和保留时间由客户端及操作系统控制。

某会话仍在运行且正处于前台查看时，该会话的完成通知只记录到历史，不会打断用户，也不会在稍后自动补弹。

在 Windows 桌面端，点击系统通知或浮卡的“查看”会请求 DSH 恢复、显示并聚焦主窗口，然后选择来源会话。DSH 必须仍在后台运行；通知回调不会重新启动已完全退出的 DSH。其他 Host 的窗口和焦点行为由各自平台决定。

## 设置说明

- **任务完成 / 错误**：分别选择关闭、应用内提示或系统通知。
- **查看结果**：跳转到来源会话，或在浮层内展开。
- **显示结果摘要 / 仅推送其他会话**：控制预览和前台过滤。
- **任务完成音效**：关闭、轻柔或清晰，支持试听与关闭。
- **通知呈现方式**：可选浮卡或提升窗口助手；平台支持和动作有差异，且与系统通知通道分开。
- **外观与历史**：位置、主题、语言、自动消失及通知历史。桌面静态 Host 最多本地保存 200 条；动态插件历史仅存在于内存。

## 故障排查

### 选择独立卡片后设置界面空白

设置页在卡片模式下不再读取悬空的更新状态对象。Card、Window、Off 三种模式都应保持设置页正常显示。如果 Client 仍缓存旧代码，请根据 Host 激活结果刷新或重启。

### 任务通知没有声音

- 选择「轻柔」或「清晰」时应立即试听。若没有声音，请检查 DSH 音频输出，并在 DSH 前台点击 **试听**。
- 浏览器或操作系统可能挂起后台 Web Audio。任务到达时插件会尝试恢复已经解锁的音频；系统通知通道恢复失败时会改用 OS 默认提示音。此时不是所选的自定义音效，声音受操作系统设置控制。
- 请检查系统通知权限、勿扰模式及应用级通知声音设置。
- 应用内提示没有 OS 声音回退；若音频不可用，请将 DSH 切到前台并点击 **试听** 解锁音频。

### 点击通知没有打开会话

保持 DSH 在后台运行。Windows 桌面版支持从最小化或托盘隐藏状态恢复；完全退出 DSH 不在通知回调的恢复范围内。请用新产生的真实任务通知验收。

### 收不到通知

检查通知类别开关、设置页中的 Host 状态和操作系统通知权限。也可在 DSH 日志或 Client 控制台查找 `[dsh-task-toast]` / `[task-toast]` 错误。

## 卸载

- **DSH 桌面应用**：在 **插件 → 已安装插件** 中卸载。
- **DSH Web profile**：

  ```sh
  dsh plugin --profile web remove dsh-task-toast
  ```

## 开发

需要 Node.js 18 或更高版本。

```sh
npm run build
npm test
node tests/stress-host.mjs
```

`lib/` 是静态发行构建，`dynamic/` 是动态备用构建。修改源码后请重新构建。开发时不要直接修改已安装的 DSH profile。
