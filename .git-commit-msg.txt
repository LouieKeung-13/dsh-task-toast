fix: card never appeared - LF line endings broke PS 5.1 here-strings (v1.5.2)

Root cause of "test card does not show in card mode": scripts/card.ps1 was
saved with LF-only line endings. Windows PowerShell 5.1 requires CRLF for
here-strings, so the parser mis-tokenized the @'...'@ block, the script
exited immediately, and the old code marked the notification silent - the
user saw nothing at all.

- build-static.mjs now normalizes scripts/*.ps1 to CRLF on every build
- card.ps1 reports {"stage":"shown"} on stdout once the window is visible;
  the Host resolves spawnCard() only then
- on early exit / 5s timeout the notification falls back to the in-app
  overlay (never silently dropped); the exact error + stderr surface in
  Settings (lastCard via /version) and in the test-button message
- /test and /card probe now await the card result and report ok/error
- monochrome UI per feedback: in-app primary buttons and the WinForms card
  (primary button, check icon) no longer use the accent color; category
  color stripes removed; settings inputs and selects share one neutral color
